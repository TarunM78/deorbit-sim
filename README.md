# sim

Simulations for the Deorbit concept (contactless ion-beam shepherding and descent kits).

* `shepherd-fleet/` — the full demo: launch, wait for targets to drift into plane, LEO ion-beam push / robotic-arm kit / GEO graveyard. Published: https://claude.ai/artifact/ADDxnBgAA938SvzvSwTKfa
* `geo-shepherd/` — the first single-file GEO graveyard proximity sim. Published: https://claude.ai/artifact/L7soop61cmxjKhst9ySkkf
* `DEORBIT.pdf` — the pitch deck the sims follow.

Run either locally with `python -m http.server` in its folder. See each folder's README.md and PHYSICS.md.
